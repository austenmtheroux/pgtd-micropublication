# Input data

Source: [Parikh et al. (2010), Genome Biology 11:R35](https://doi.org/10.1186/gb-2010-11-3-r35),
[GSE17637](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE17637).
Files were obtained from the [archived supplementary website, 1 August 2016 snapshot](https://web.archive.org/web/20160801030926/http://dictygenome.bcm.tmc.edu/~anup/RNAseq/).

| File | Contents |
| --- | --- |
| `discoideum_normalized_data_set.txt` | D. discoideum scaled abundances; target `DDB_G0278731` (pgtD). |
| `purpureum_normalized_data_set.txt` | D. purpureum scaled abundances; target JGI `87341` (`DPU_G0074572`). |
| `Supplementary Table 5.xls` | D. discoideum published differential-expression statistics. |
| `Supplementary Table 6.xls` | D. purpureum published differential-expression statistics. |

Developmental samples are D. discoideum AX4 and D. purpureum DpAX1,
sampled every 4 h from 0–24 h (two replicates each). Cell-type samples are
D. discoideum NC4 (bio2, bio4) and D. purpureum DpAX1 (bio1, bio2).
Replicate labels are specific to each experiment.

The gene pairing is documented in [Sucgang et al. (2011)](https://doi.org/10.1186/gb-2011-12-2-r20),
Additional file 3, Table S4; Additional file 1, Table S17 also lists the identifiers.
